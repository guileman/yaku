# Yaku Energía — sitio comercial y animación interactiva

Microturbinas hidroeléctricas de Yaku Energía.

- `index.html` — sitio comercial (turbina axial **LH 140** y **Pelton Cube 230**). Se abre con doble clic; sin dependencias externas.
- `animacion-axial/` — animación 3D interactiva de la LH 140 (three.js). Abre con doble clic; ver su `README.md` para regenerar el build.
- `FALTANTES.md` — datos pendientes de completar (precios, garantía, contacto, etc.) e inconsistencias detectadas entre documentos.

Los datos editables (WhatsApp, email, tablas de potencia, ensayos) están en `js/data.js`.
